Level 1 / HTML basics

A first look at HTML.

HTML is the set of building blocks behind every webpage. Learn what the tags mean, how a page is organized, and how to describe content clearly.

Keep in mindHTML describes the meaning and structure of content. CSS controls its appearance; JavaScript can make it interactive.
01

What is HTML?

HTML stands for HyperText Markup Language. It uses elements, written with tags, to identify parts of a page such as a heading, paragraph, link, or image.

A tag is not a programming command: it labels content so browsers and assistive technologies can understand its role. Most elements have an opening tag, content, and a closing tag. 

<p>This is a paragraph.</p>

Here, <p> opens the paragraph and </p> closes it.

02

HTML document structure

A webpage is a document with an outer <html> element. Inside it, <head> holds page information and resources, while <body> holds the content people see. 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello, web!</h1>
  </body>
</html>

The browser tab gets its title from <title>. The heading belongs in the body, not the head.

03

Doctype and essential elements

<!doctype html> tells the browser to use modern HTML. It is a declaration, not a regular HTML element.

<html lang="en"> wraps the whole document; its lang attribute tells tools which language to expect. The <head> contains metadata, and the <body> contains visible page content.

Include a character encoding and viewport setting in the head. They help text display correctly and let the page fit mobile screens. 

<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
04

Headings: <h1> to <h6>

Headings label sections and show how ideas are organized. Use <h1> for the page's main topic, then use lower-level headings for nested sections. Choose a level for its meaning, not just its size. 

<h1>My garden</h1>
<h2>Plants I grow</h2>
<h3>Herbs</h3>

Plants I grow

Herbs

05

Paragraphs: <p>

Wrap a paragraph of text in <p>. Browsers add space around paragraphs by default. Use a new paragraph when the thought changes, rather than adding repeated spaces in the source. 

<p>HTML gives content a clear structure.</p>
<p>This is a second paragraph.</p>
06

Text formatting

Some text elements carry meaning as well as a visual style. Prefer semantic elements when the meaning matters: screen readers may announce emphasis or importance differently.

<strong> means important: Read this first.

<em> adds emphasis: Really important.

<mark> highlights: Find this phrase.

<b> draws attention without extra importance.

<i> marks an alternate voice or term.

<u> marks an annotation; avoid confusion with links. 

<p><strong>Important</strong> and <em>emphasized</em> text.</p>
07

Comments

Comments are notes in your HTML source. Browsers do not show them as page content. Use them to leave a helpful note for someone reading the code later. 

<!-- Add the page introduction below -->
<p>Welcome to my page.</p>

Do not put passwords or private information in comments: anyone can view the page source.

08

Links: <a>

The anchor element makes a link. Its href attribute gives the destination, while the text between the tags tells people where the link goes. 

<a href="https://developer.mozilla.org/">
  Read the MDN web docs
</a>

For a link that opens a new tab, use target="_blank" and rel="noopener noreferrer". Only do this when it helps the reader.

09

Images: <img>

The image element embeds an image and is a void element, which means it has no closing tag. Give it a src (image location) and useful alt text describing the image's purpose. 

<img
  src="images/greenhouse.jpg"
  alt="Seedlings growing in a sunny greenhouse"
  width="640"
  height="420">

Use alt="" for a purely decorative image. Never leave out the alt attribute.

10

Lists: <ul>, <ol>, <li>

Use an unordered list when order does not matter, and an ordered list when the sequence matters. Each item goes inside an <li> element.

Unordered list 
<ul>
  <li>Soil</li>
  <li>Seeds</li>
</ul>
Ordered list 
<ol>
  <li>Fill the pot</li>
  <li>Plant a seed</li>
</ol>
11

Line breaks and horizontal rules

<br> starts a new line within the same piece of text, such as an address or a poem. <hr> marks a change of topic or scene. Both are void elements and have no closing tags. 

<p>12 Garden Lane<br>
Greenwich<br>
London</p>
<hr>

Do not use <br> to create space between paragraphs. Use separate paragraphs and style their spacing with CSS.

12

Basic attributes

Attributes add information to an element. They go inside the opening tag, usually as a name, an equals sign, and a quoted value. Common examples include href on links, src and alt on images, and id for a unique page target. 

<a href="about.html" id="about-link">
  About this page
</a>

Some attributes are global and work on many elements. For example, id should be unique on the page, and class can be reused to group elements for CSS or JavaScript.

Your first-page checklist

Start with the doctype, add html, head, and body, then give your content meaningful structure. Indent nested elements so the shape of the document is easy to follow.
