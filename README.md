# Markup Field Notes

A small, static HTML learning project that moves from HTML fundamentals to practical page-building projects. Each course page links to the other levels in the course navigation.

## Course Pages

1. [HTML Basics](html-basics/index.html) — document structure, headings, text, links, images, lists, and attributes.
2. [Intermediate HTML](html-intermediate/index.html) — tables, forms, semantic elements, media, and file paths.
3. [Advanced HTML](html-advanced/index.html) — modern HTML features, accessibility, structured data, graphics, storage, and performance.
4. [Real-World Projects](html-real-world/index.html) — practical page briefs for applying HTML skills.

## Open the Pages

Open `html-basics/index.html` in a browser to start, then use the course navigation to move between levels. No build step is required. You can also open the project folder in VS Code and use a local web server or the Live Server extension if you prefer.
